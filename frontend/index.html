    Blockchain structure

    Click any block to inspect its header fields. Your live chain is rendered below.

    Genesis block

    The first block anchors the chain. Its previous hash is a fixed sentinel — not a real prior block.

    Block linking

    Each block stores the hash of its predecessor, forming an immutable linked list.

    Hash chaining

    Altering any block changes its hash, breaking the link to the next block. Try the tamper demo.

    Merkle trees

    Educational demo: transactions are hashed pairwise up to a root. This simulator stores a flat tx list in block hashes — Merkle roots are not in headers yet.

    Root hash summarizes all transactions — changing one leaf changes the root.
